# Запуск

```
npm install
npm start          # http://localhost:3000
```
Первый вход: **admin / admin**. Пароль админа поменяйте сразу во вкладке «База → Продавцы».

Все данные (заявки, телефоны, продавцы) лежат в одном файле `data.db` рядом с `server.js`.
Чтобы сделать резервную копию, достаточно скопировать этот файл.

## С чего начать
1. Войти как admin, открыть «База → Телефоны» и добавить позиции (модель, память, цвет, SIM, цена).
2. В «База → Продавцы» завести каждого продавца с логином и паролем.
3. Продавцы входят под своими логинами и создают заявки. Телефон выбирается только из базы.

## Хостинг
Базе нужен постоянный диск: файл `data.db` не должен стираться при перезапуске.
Бесплатный Render такого диска не даёт, данные будут пропадать. Подходят:
- **VPS** (любой, от ~200 ₽/мес): `npm install && npm start`, лучше через `pm2`.
- **Railway / Fly.io** с подключённым volume. Путь к базе задаётся переменной `DB_FILE`, например `/data/data.db`.

Для Telegram мини-аппа нужен HTTPS-адрес. Его вставляют в @BotFather → бот → Bot Settings → Menu Button.
