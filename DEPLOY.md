# Запуск и публикация

Сайт статический (Vite), сервера и внешней базы нет. Всё хранится в localStorage браузера:
телефоны, заявки и аккаунты. У каждого браузера и устройства своя копия данных.

Первый вход в новом браузере: `admin` / `admin`. Смените пароль в «База → Продавцы».
Пароли лежат в браузере, поэтому они защищают только от случайного входа.

## Локально

```sh
npm install
npm run dev      # http://localhost:5173
npm test
```

## Vercel

Root Directory — `./`, Framework — Vite (указан в `vercel.json`). Переменные окружения не нужны.
Каждый push в `main` публикуется автоматически.

Перенос данных между браузерами: «База → Резервная копия базы → Экспорт / Импорт».
